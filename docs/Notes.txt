Phantom Recon - C++ program
- Enumerates the computer's Hard Drive to look for .exe files for full mode scan
- Fast Mode only checks installed programs (via windows) for fast mode
It will ideally do the following
- will check file location, size, md5, and other pertinent info to try to verify it's legit
- will check to see if there's an updated version available
- will do static analysis to assign malware score based on specific features (tbd but like function calls, etc)
- will look at CVE's identified for both this version and the update (if available)
** i'm open to additional suggestions.  This is intended to be a defensive endpoint auditing and threat-hunting application
